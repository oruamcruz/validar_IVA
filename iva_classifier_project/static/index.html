Como ajustar os códigos
Abra a pasta regras. O arquivo ivas.json contém os mapeamentos da tabela que você forneceu. Para adicionar ou corrigir códigos, edite esse arquivo preservando o formato JSON.
As regras de serviços J1/J2/J3/J4 são determinísticas e não são alteradas pelo Gemini. A aplicação não lança nada no SAP; apenas sugere classificações para conferência.
